# 快捷键速查

Windows 上把 ⌘ 换成 Ctrl，⌥ 换成 Alt。

## 录音

| 按键 | 作用 |
| --- | --- |
| ⌘⇧R | 空闲时开始录音（可在设置里改） |
| ⌘N | 记一句笔记，回车保存，Shift+回车换行 |
| ⌘V | 把剪贴板里的图片记到当前时间点 |
| ⌘⇧P | 用 iPhone 直接拍照插入（仅 Mac） |

## 看稿

| 按键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ↑ ↓ | 上一段 / 下一段 |
| 按住 → | 临时两倍速，松开恢复 |
| 双击 | 就地改这一段，回车保存，Esc 放弃 |
| ⌘B / ⌘U | 选中文字后加粗 / 下划线 |
| ⌘F | 查找和替换 |
| ⌘E | 复制不带时间戳的纯文本 |
| ⌥ 点复制 | 临时选择复制格式 |

## 窗口

| 按键 | 作用 |
| --- | --- |
| ⌘B | 收起 / 展开项目栏 |
| ⌘⇧B | 打开 / 收起课后笔记 |
| ⌘K | 搜索项目和分组 |
| ⌘, | 打开设置 |
| ⌘/ | 查看全部快捷键 |
| Esc | 关掉当前弹层 |

## 容易漏掉的

- 鼠标在摘要标题上停一两秒，会浮出「重新生成」。
- 图片拖到段落的左侧或右侧，会变成文字环绕；拖到上沿或下沿，单独占一行。
- 笔记卡片里的图片右键，有五种排版方式。
- 选中文稿里的话，点浮动工具栏最右边的按钮，可以引用到笔记。
- 项目栏收起时，鼠标移到左上角的开关按钮上，项目栏会临时浮出来。
